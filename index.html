agentprobe

1.

Regression testing for LLM agents

I built a regression tester for LLM agents. Each case runs many times and is judged on the full trace and tool calls. A Typer CLI and a GitHub Action run it, with HTTP, MCP and Python adapters.

  • Every case runs many times (default 10)
  • False regression alarms on unchanged flaky agents fell from 70.6% to 0.9% versus a single-run check, in simulation
  • 1,145 Python tests, 184 web unit tests and 14 end-to-end specs, with 97% coverage on core and API

stockpilot

2.

Stock screener with a plain-English query engine

A screener for about 100 NIFTY stocks with filter, sort, search, a watchlist and 3-way compare. You can search in plain English. An offline rule parser answers first, a cloud LLM helps when it can, and every model reply is schema-checked.

  • About 100 NIFTY stocks (NIFTY 50 and NIFTY Next 50)
  • Evaluation harness with 70 hand-written queries. The offline rule parser matches 69 of 70. I wrote the expected answers myself and have not reviewed them independently, so the result says little about real-world accuracy.
  • The cloud LLM alone matched 34 of 70, mostly because calls hit the 8 second timeout and fell back to the rule parser

investorlens

3.

UX research app with AI analysis

I built a research app that links interviews, findings, personas, journey maps and a recommendations board. It has shared Zod validation, URL-based filters, cross-entity search, a live dashboard and a printable report. An opt-in Gemini feature suggests pain points that a person must approve.

  • Up to 15 candidate pain points extracted per transcript
  • Guards on the AI output: schema validation, verbatim quote checks, invalid finding IDs downgraded
  • Human approval before a single-transaction save

canvaslint

4.

Canvas 2D debugger for Chrome DevTools

A Manifest V3 Chrome extension that records Canvas 2D calls and replays them in a DevTools panel. A slider scrubs through the command history. Capture, a 10,000-slot ring buffer and basic replay work. Live panel updates, block grouping and pause controls do not work yet.

  • Canvas 2D calls recorded through prototype wrappers and batched per animation frame, with an early flush at 500 queued commands
  • 10,000-slot ring buffer in the service worker
  • Replays from a command log instead of pixel snapshots, for exact replay at lower memory cost
